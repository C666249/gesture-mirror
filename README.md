# 幻境相机 · Gesture Mirror

用摄像头照见真实，用手势在画面里开出一个**动漫世界**。

纯前端单文件（`index.html`），无构建、无框架、无后端。摄像头画面全部在本机 WebGL 里处理，不上传任何数据。

线上地址：**https://c666249.github.io/gesture-mirror/**

---

## 怎么玩

| 动作 | 效果 |
| --- | --- |
| **拇指 + 食指拉开** | 两点之间的矩形里，画面变成动漫（`取景框`） |
| **两根手指（食指~中指）** | 雾雨 · 雨夜（雨丝 / 玻璃水珠 / 飞溅 / 雾气） |
| **三根手指** | 樱吹雪（分层花瓣，近景虚化） |
| **四根手指** | 萤火（呼吸光点） |
| **握拳（0 根）** | 关闭所有特效 |
| **张开手掌（5 根）** | 全屏爆散 |

手柄以外的兜底：底部按钮 `1 / 2 / 3 / ✕`、键盘 `1 2 3 0 Esc F`。

> 取景框优先：拇指和食指明显张开时进入取景，不再数手指，避免冲突。

## 动漫滤镜是怎么做的

三层 WebGL 通道，每帧四次全屏绘制：

1. **卡通化**（`FS_CARTOON`）
   - 9 点**双边滤波**：只平均亮度相近的邻居 —— 抹平皮肤/织物纹理，但保留轮廓
   - Sobel 墨线写入 alpha 通道
   - 提亮暗部 → 亮度 S 曲线 → 中间调提饱和
   - **肤色重绘**：检测 `R-B` 偏暖区域，按亮度重构浅粉肤色，而不是给棕色加亮（否则就是"阿宝色"）
   - **暗部填靛蓝** + 亮度 6 级分层 —— 动画平涂的两条命脉
2. **Bloom**：亮部提取 → 横/纵两次高斯（1/4 分辨率）
3. **合成**：墨线（皮肤区域抑制 95%，否则脸上会出现黑河）+ 框内动漫/框外现实的圆形软边混合 + 边框辉光 + 暗角 + 胶片颗粒

框选不是贴个滤镜层：`uRect` 在合成着色器里做软边遮罩，框外画面会降饱和、压暗、偏冷，框内提亮，让「另一个世界」跳出来。

## 天气特效

2D Canvas 叠加层，和 WebGL 分帧驱动：

- **雨**：三层雨丝（远中近，不同粗细/速度/透明度）、斜向下落、落地飞溅、玻璃水珠（暗芯 + 亮环 + 高光 + 下滑拖尾）、底部雾气、随机雷闪
- **樱**：4 张预渲染花瓣贴图（线性渐变 + 径向高光 + 中脉），230 片，按深度分配大小/速度/透明度，近景 `filter: blur()` 虚化，翻面用 `scale(1, |cos|)`
- **萤火**：预渲染辉光 sprite + 加法混合 + 呼吸曲线

## 手势识别

MediaPipe Hands（CDN 动态加载），最多 2 只手。

- **四个源自动选**：npmmirror 国内镜像 → jsdelivr → fastly → unpkg，并行探测哪个通用哪个
- **只数食指到小指**，故意不数拇指 —— 握拳时拇指最容易误判
- 连续 6 帧一致才触发，防抖
- 取景框：每只手的拇指尖/食指尖做对角点，双手时取并集；指数平滑跟手

页面右上角有常驻状态灯（摄像头 / 引擎 / 当前识别），出问题能一眼看出卡在哪。

## 调试参数

URL 后加 hash：

```
#demo                     演示模式（不开摄像头，可直接拖拽画框）
#demo&img=test/xxx.png    用图片代替摄像头（看滤镜效果）
#r=0.2,0.2,0.7,0.8        强制取景框（左上 xy / 右下 xy，屏幕归一化坐标）
#m=rain                   直接进入某个特效（rain / sakura / firefly）
#auto                     进页面自动申请摄像头（自助/展台模式）
```

## 本地运行

```bash
python -m http.server 8080
```

访问 http://localhost:8080 —— `localhost` 也算安全上下文，摄像头可用。

## 已知限制

- 需要 **WebGL2**（Safari 15+、Chrome/Edge 全部现代版本都可以）
- 首次要下载约 6MB 的手势模型，慢网络下要等几秒，状态灯会显示"加载中"
- 人脸表情（张嘴/眨眼）需要额外的 FaceLandmarker 模型，这一版没做，只做了手势
